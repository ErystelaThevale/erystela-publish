# Erystela Publish

A collection of completed tools and small projects, published here for public reference.
Development happens elsewhere; this repository holds finished, publish-ready snapshots.

## Projects

### Category Relationship Map (`classification/`)

Visualizes how Web of Science subject categories relate to one another, based on which
theories reference which categories. Category pairs that co-occur under the same theory
are treated as strongly connected.

- **Live demo**: https://erystelathevale.github.io/erystela-publish/classification/output/category_graph.html
- **Source**: [`classification/src/`](classification/src/)
- **Spec**: [`classification/doc/CLASSIFICATION_SPEC.md`](classification/doc/CLASSIFICATION_SPEC.md)
